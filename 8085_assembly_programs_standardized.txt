8085 PROGRAMS (STANDARDIZED ADDRESSES: INPUT 8000H, PROGRAM 9001H, OUTPUT 8050H)
================================================================================

1. Program to add two 8-bit numbers.
Statement: Add numbers from memory location 8000H & 8001H and store result in memory location 8050H.

// Program starts at 9001H
LDA 8001H   // Load contents of memory location 8001H to accumulator
MOV B,A     // Move contents of accumulator to B register
LDA 8000H   // Load contents of memory location 8000H to accumulator
ADD B       // Add contents of accumulator and B register
STA 8050H   // Store contents of accumulator in memory location 8050H
HLT         // Terminate the program

Input:
Memory Location   Data
8000H             45H
8001H             53H

Output:
Memory Location   Data
8050H             98H

--------------------------------------------------------------------------------

7. Program to add two 16-bit numbers.
Statement: Add numbers 1124H & 2253H and store result in memory location 8050H & 8051H.

// Program starts at 9001H
LXI H,1124H // Load 16-bit data 1124H to HL pair
LXI D,2253H // Load 16-bit data 2253H to DE pair
MOV A,L     // Move contents of register L to Accumulator
ADD E       // Add contents of Accumulator and E register
MOV L,A     // Move contents of Accumulator to L register
MOV A,H     // Move contents of register H to Accumulator
ADC D       // Add contents of Accumulator and D register with carry
MOV H,A     // Move contents of Accumulator to register H
SHLD 8050H  // Store contents of HL pair in memory address 8050H & 8051H
HLT         // Terminate the program

Input:
Register Pair   Data
HL              1124H
DE              2253H

Output:
Memory Location   Data
8050H             77H
8051H             33H
